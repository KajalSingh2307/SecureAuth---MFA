Cybersecurity Reference

Time-Based OTP (TOTP) Uses RFC 6238. Code changes every 30 seconds based on a cryptographic hash function combining the secret key and Unix epoch time.
Phishing Resistance Unlike SMS or Email OTPs, TOTP secrets are held locally on physical devices, reducing interception risk via SIM swapping.
Defense-in-Depth Even if password credentials leak, attacker cannot gain access without direct control of the user's registered physical authenticator app.
